**Обыкновенная овсянка** — мелкая птица семейства овсянниковых, хорошо узнаваемая по яркому золотисто-желтому оперению на голове и груди.

Здесь живут инструменты для разработки около «1С:Предприятие 8» и OneScript.

## Главное

- **[1C: Platform Tools](https://github.com/yellow-hammer/vscode-1c-platform-tools)** — расширение VS Code (Cursor) для разработки на 1С · [документация](https://yellow-hammer.github.io/vscode-1c-platform-tools/) · [Marketplace](https://marketplace.visualstudio.com/items?itemName=yellow-hammer.1c-platform-tools)
- **[MCP 1C: Platform Tools](https://github.com/yellow-hammer/mcp-1c-platform-tools)** — MCP-сервер, через который AI-агенты работают с расширением
- **[dev-rules](https://github.com/yellow-hammer/dev-rules)** — обыкновенные стандарты разработки на 1С · [сайт](https://yellow-hammer.github.io/dev-rules/)
- **[OneFlag](https://github.com/yellow-hammer/oneflag)** — self-hosted сервис фича-флагов на OneScript ([SDK](https://github.com/yellow-hammer/oneflag-sdk))

## 1С

- [package-manager-e1c](https://github.com/yellow-hammer/package-manager-e1c) — менеджер пакетов: расширения и обработки из GitLab и GitHub Releases
- [prometheus-e1c](https://github.com/yellow-hammer/prometheus-e1c) — экспорт метрик в формате Prometheus
- [md-sparrow](https://github.com/yellow-hammer/md-sparrow) — чтение и запись метаданных в формате выгрузки конфигуратора (XML) и 1С:EDT (`.mdo`)
- [namespace-forest](https://github.com/yellow-hammer/namespace-forest) — схемы форматов исходников: XSD выгрузки конфигуратора и метамодель 1С:EDT
- [onec-debug-adapter](https://github.com/yellow-hammer/onec-debug-adapter) — Debug Adapter Protocol для 1С
- [vanessa-bootstrap](https://github.com/yellow-hammer/vanessa-bootstrap) — шаблон проекта
